Help place a new brand asset: $ARGUMENTS

1. Map the asset type to the correct destination folder under `maintain/`
   (`01 Visual Identity`, `02 Internal Materials`, `03 Social Media`,
   `04 Canva Assets`). If it doesn't clearly fit one, ask — do NOT invent a new
   top-level folder.
2. Propose a filename following `maintain-<context>-<descriptor>[-variant].<ext>`
   (lower-kebab), and confirm the extension/format expected for that
   destination (e.g. LinkedIn cover dimensions, presentation format).
3. State the full target path and the naming, then wait for confirmation before
   creating or moving any file.

Do not overwrite existing delivered assets. If a matching file already exists,
surface it instead of duplicating.
